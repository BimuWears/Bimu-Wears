BIMU WEARS WEBSITE
===================

Files:
- index.html: customer storefront with cart and checkout form
- admin.html: simple product manager
- assets/logo.png: your logo

How to use:
1. Open admin.html to manage products.
2. Put product photos inside assets/ and set image path, e.g. assets/shirt1.jpg.
3. Upload the whole folder to Netlify Drop (free) or GitHub Pages.

Important:
This is a free static starter website. The checkout collects order details in the browser and shows a confirmation; it does not yet send orders to a server/email or process online payments. For real order receiving, connect a form service or backend later.
